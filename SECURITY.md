# Security policy

## Supported versions

Security fixes target the latest stable release and current development on `main`. Older releases do not have a
separate security maintenance commitment; please update to the latest stable version when possible.

## Report a vulnerability privately

Use [GitHub private vulnerability reporting](https://github.com/Naveen022006/Trayloom/security/advisories/new).
If that is unavailable, email **kanagunaveen21@gmail.com** (maintainer: **Naveen022006**) with the subject
`Trayloom security report`.

Please do not publish exploit details in a public issue or PR before a fix can be coordinated. Include the affected
version, Windows version, impact, reproduction steps, and a minimal proof of concept if available. Remove credentials,
tokens and other personal data from logs and screenshots. Test only on systems and data you are authorized to use.

The maintainer will review reports and coordinate fixes and disclosure with the reporter as availability permits.
There is no guaranteed response deadline or paid bug bounty. Ordinary bugs and feature requests belong in public issues.
