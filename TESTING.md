# Things only a person can test

Everything else (every tray tab, all settings pages, the Features hub, the first-run guide, the Dynamic Island pages, the
Command Bar, clipboard window, shelf, scratchpad, screenshot, text from screen, color picker, recording and export, the
cleaner scan, the lists in Packages / App updates / Kill Process / Port Manager, German and Japanese) was driven on a
test copy of the app. The items below need real keys, real mouse gestures or other programs, so please try them yourself.

Tip: turn the feature on in **Settings > Features** first. If something grabs a key you need, uninstall that feature there.

| Feature | How to try it | What should happen |
| --- | --- | --- |
| Alt+Tab switcher | Install *Window switcher*, open three apps, press Alt+Tab, keep Alt held and tap Tab, then let go. | A strip of window previews replaces the Windows one; the chosen window comes to the front. Esc cancels. Releasing Alt never leaves Alt "stuck". |
| Switcher: windows of one app | Press Alt+` (backtick) with two Explorer windows open. | Only the windows of the front app are listed. |
| Taskbar hover previews | Install *Taskbar Preview*, rest the pointer on an open app's taskbar icon. | A preview of its windows appears after the open delay; clicking a preview raises that window. |
| Taskbar clicks | Install *Taskbar clicks*, click a running app's icon while it is in front. | It minimizes (or hides, or cycles windows, depending on the setting). Clicking again brings it back. |
| Window edge snapping | Install *Window layout*, turn on "Snap windows at screen edges", drag a window by its title bar to the left edge. | A highlighted area shows; letting go snaps the window to that half. Corners give quarters. |
| Move / resize by dragging | Hold Ctrl+Alt and drag anywhere inside a window (add Shift to resize). | The window moves (or resizes) without grabbing its title bar. |
| Window layout shortcuts | Ctrl+Alt+Left / Right / Enter / C on a normal window. | Left half, right half, maximize, center. Ctrl+Alt+R restores. |
| Quit on close | Install *Quit on close*, close the last window of Notepad with the X. | Notepad quits instead of staying in the tray. Apps in the Exceptions list stay open. |
| Quit & close protection | Install it, press Alt+F4 once on a window, then press and hold it. | A short hold is needed; a quick tap does nothing; the hold shows a progress ring and then closes. |
| Super key | Install *Super key*, hold Caps Lock and press H (or any key). | The key acts as Shift+Ctrl+Alt+Win+H. A quick tap of Caps Lock does what "A tap on its own" says. Uninstall and check Caps Lock works normally again. |
| Text snippets | Add a snippet (trigger `;sig`), type `;sig` in Notepad. | The trigger is replaced by the full text. Ctrl+Alt+Win+L opens the quick snippet menu. |
| Side and extra mouse buttons | With a mouse that has side buttons, install *Side buttons* and click Back / Forward in a browser. | Pages go back and forward. *Mouse button shortcuts* sends the key combination you set. |
| Focus follows mouse | Install it, move the pointer across two windows without clicking. | The window under the pointer gets focus after the delay. |
| Smooth / linear scrolling, invert scrolling | Scroll a long web page with the wheel. | Smooth: animated. Linear: same distance every notch. Invert: the opposite direction. Uninstall and check the wheel is normal again. |
| Radial menu | Press Ctrl+Alt+Win+Space (or use the mouse button you set). | A wheel of actions opens at the pointer; moving into a slice and releasing runs it. |
| Recording with real clicks | Press Ctrl+Alt+Win+5, drag a region, click around and type for 5 seconds, stop. | The editor opens; the click ring and pointer track are visible; auto-zoom follows clicks; Save writes an .mp4 that plays. |
| Permission alert (AI Agents) | Turn on **AI Agents** in the Dynamic Island, then start a Claude Code session that asks for a permission (for example run a shell command that needs approval). | The island pops out to say that session needs you (you must first install the hook from the AI Agents settings, which edits `~\.claude\settings.json` after making a backup). The permission itself is still answered in Claude Code. |
| Clipboard history capture | Install *Clipboard*, copy text in three different apps, press Ctrl+Alt+Win+V. | Each copy is listed (newest first); Enter or a click pastes it into the previous app; pinned items survive "Clear unpinned". |
| Paste as plain text | Copy bold text from a web page, press Alt+Shift+Win+V in Word or Notepad. | The text arrives without formatting. |
| Explorer cut and paste | Install *Cut & paste*, select a file in File Explorer, press Ctrl+X, open another folder, press Ctrl+V. | The file moves (it does not copy); a small floating panel shows what is cut. In a text box Ctrl+X / Ctrl+V still work as normal. |
| Explorer rename | Select a file in File Explorer and press F2 (with the rename shortcut installed). | The name goes into edit mode; typing and Enter renames it. Not active inside text fields. |
| Shelf | Drag a file out of Explorer while shaking the mouse (or press Ctrl+Alt+Win+D) and drop it on the shelf. | The file is held; dragging it out of the shelf drops it in another folder. |
| Mute microphone | Press Ctrl+Alt+Win+M twice. | The tray icon shows muted, then back. Uninstalling the feature while muted unmutes. |
| Cleaning Mode | Start it (only with the keyboard and mouse free to lock) and wait for the timer. | Keyboard and mouse are locked; they work again when the timer ends. |
| Move the Dynamic Island | Turn the island on. With the pointer, press on the closed island and drag it a few centimeters, then let go. Try a quick click without moving, too. | A small ghost follows the pointer and jumps to where the island will land (it snaps to the edges, to the center and to the screen edge). Letting go leaves it there; a plain click still opens it. Pressing the right button while dragging cancels. After the move the island stays put and opens its pages away from the edge it rests on. |
| Place the island from Settings | Settings > Dynamic Island > Behavior > Position: click each of the six tiles, move "Distance from edge", press "Move island...", then "Reset position". Also try "Lock position" and drag the island. | The island follows each choice at once and the tile for it is selected (a dragged island shows "Custom position"). With a distance above 0 it floats as a capsule. "Move island..." shows "Drag to move" with Reset and Done; Done or a click elsewhere leaves it. "Reset position" returns to the top center. With the lock on, dragging does nothing but "Move island..." still works. |
| Drag across displays with different scaling | With two displays at different scale (for example 125% and 100%), drag the island from one to the other and let go. Open it afterwards. | The ghost keeps the grip point and shows the island at the size of the display it is over; after letting go the island is the right size and fully inside that display, with no jump or flicker. In Settings > Behavior > Display "Choose a display" now names that display. |
| Island at the bottom | Place the island at "Bottom center" or "Bottom right", then open it by click, by hover, and by scrolling the wheel up over it. Close it by scrolling down over its top row, and open the music, calendar and timer pages. | Pages open upward, fully inside the screen, above the taskbar; the quick buttons stay on the sides, the bottom row goes above the page. With Gestures on, the wheel opens upward (scroll up) and closes downward; Settings shows the matching caption and "Distance from bottom" in Layout > Capsule fit. |
| Unplug and replug a display | With the island placed on an external display ("Choose a display"), unplug it (or turn it off), wait a few seconds, then plug it back in. | The island moves to the main display and Settings shows "This display isn't connected...". When the display returns the island goes back to it at the position it had there. Closing the laptop lid with the island on the built-in display shows it on the main display afterwards, too. |
| Auto-hide taskbar | Turn on "Automatically hide the taskbar" in Windows Settings, then place the island at "Bottom center" and at "Top center". | A bottom island sits just above the screen edge and the taskbar still slides up over it when you push the pointer to the bottom; a top island is where it always was. No part of an open page is cut off. |
| Virtual desktops | Place the island at "Bottom right", then switch to another virtual desktop (Win+Ctrl+Left / Right) and back; open it on each. | The island is on every desktop at the same place and opens normally. |
| Install offer | Run the downloaded `Trayloom.exe` from the zip folder. | The "Install Trayloom" window appears. Install copies to your account, adds a Start menu shortcut and starts the installed copy. |
| Spotify: connect | Create your own Spotify app (see docs/INSTALL.md, Spotify and YouTube Music), paste its Client ID in Settings > Dynamic Island > Content > Now Playing > Music services, click Connect, allow access in the browser. | The tab says Spotify is connected; the card says "Connected as" your name and the button becomes Disconnect; the island Library gets a Spotify tab. Quit and start Trayloom: still connected. `settings.json` has no token, and `%APPDATA%\Trayloom\music\spotify.bin` is binary (open it in a text editor to see). |
| Spotify: browse | Open the island music page > Library > Spotify. Try the Playlists, Liked Songs and Recently played tabs; type two letters of an artist; press the All, Songs, Albums, Artists and Playlists chips; click "Show all"; open an album, an artist and a playlist you own, then a playlist you only follow. | Results appear about half a second after you stop typing; All groups four per section with Show all (N); Songs/Albums/Artists page ten at a time with Show more; an album lists its songs; a followed playlist says Spotify lists songs only for playlists you own or collaborate on, and still has Play and Open in Spotify. Artwork is square and never cropped. |
| Spotify: play with the app open, closed, and phone only | With a Premium account, click a song with Spotify open on this PC; close Spotify and click again; then close it and open Spotify on your phone only. | App open: the song plays there and a note says "Playing on" this PC. App closed: the note says "Starting Spotify..." and the song plays within about 15 seconds. Phone only: it plays on the phone. If nothing is open anywhere you are told to open Spotify. |
| Spotify: queue, Up next, Liked Songs | Use a song's "..." menu > Add to Queue (or Ctrl+Enter on the highlighted row). Open Up next while Spotify plays. Click a song in Liked Songs and let it end. | "Added to the queue"; Up next lists Spotify's real queue and its refresh button reloads it; Liked Songs carries on with the next liked songs. |
| Spotify: free account | Connect an account without Premium (it must be added in your app's User Management). Click a song. | Search and browse work; the song opens in the Spotify app with the note that Premium is needed to play from the island; menus say Open in Spotify. |
| Spotify: errors | Click Connect, then Cancel; click Connect and close the browser tab (wait 5 minutes or Cancel); click Connect twice; use a wrong redirect URI in your Spotify app; connect an account that is not in User Management; Disconnect; remove Trayloom at spotify.com/account/apps while connected; switch Wi-Fi off and on in the island. | Each shows its own plain message in the card or the island (cancelled is silent, a closed tab times out, the second Connect replaces the first, "Invalid redirect URI" is explained while connecting, an unlisted account says to add it in User Management, the revoked sign-in asks to Reconnect, offline says so and recovers by itself). Disconnect leaves no spotify.bin. |
| YouTube Music: without a key | Turn on "Show YouTube Music in the island", open Library > YouTube Music, type a song and press Enter. Click Open YouTube Music, Liked music and Library. | Pressing Enter opens the YouTube Music search in your browser; the island says to add an API key to see results here; the link pills open the matching pages (and the YouTube Music app if it is installed). |
| YouTube Music: with a key | Paste a YouTube Data API key and click Save; search with Enter; use the Songs and Playlists chips; click a result; open a playlist; use "..." > Open in YouTube. Try a wrong key, then Remove. | "The key works." then "Saved key ending in ..."; results show 16:9 thumbnails; a click opens the song in your browser (or app) and the island controls follow that player; a wrong key says "This key isn't valid."; Remove deletes it and the island goes back to the no-key view. The key never appears in the box again or in the log. |
| Music page keyboard | With the Library open on each source: Ctrl+F and "/" focus the box; type a letter without clicking; Down/Up/PageDown then Enter; Esc repeatedly; leave the box focused while a song changes. | The box takes the keyboard only from those gestures; Esc clears the text, then leaves the box, then closes the open list, then the Library; focus and caret survive a track change; Space plays/pauses unless the box has text. |
| Source switcher and Apple Music regression | With Apple Music only: use the Library as before. Turn Spotify on, then YouTube Music on; switch between Apple Music, Spotify and YouTube Music; change song. Turn both off again. | Apple Music alone looks and behaves exactly as before. With two or more sources a small switcher appears above the list, your choice is remembered, and the cover of an Apple Music song still opens the Apple Music Library. With both off there is no switcher and no extra toolbar change. |

After testing, open Settings > Features, check which input features are still installed, and uninstall any you do not want.
| Wi-Fi switch and networks | From the island Wi-Fi page, the tray Network tab card and the Command Bar, switch Wi-Fi off and on; disconnect and reconnect; join a password network (wrong password first), an open network and an enterprise network. Also try location off for desktop apps and airplane mode. | The switch and list follow each action; an enterprise network opens Windows; with location off the page explains it and links to the setting; airplane mode is reported. |
| Away mode with real windows | Install *Away mode*, leave the PC idle for the set time, then move the mouse. Repeat with "Lock the PC too" (unlock restores), with two displays (cover on both), a video playing, a full-screen presentation, Camera preview open, and by undocking a display while away. | Everything is minimized, then returns in the same order with the same focus. A playing video, a presentation or an app using the microphone or camera prevents away. Nothing is lost when a display goes. |
| Away mode face detection | Turn on face detection, walk away for 3 minutes, come back and look at the screen. | Windows return within about 6 seconds; the camera light is on only while away. |
| GitHub tokens and CLI | Connect with a classic token, then with a fine-grained token; run `gh auth logout` while connected; disconnect. | Both tokens connect (the fine-grained one shows "Needs a classic token" for notifications); signing out of gh shows signed out; disconnect removes `token.bin`. |
| Screen time across midnight and sleep | Use the PC across midnight and after the PC sleeps. | The day is split at midnight and the time asleep is not counted. |
